    如何使用？

    1. 训练完成后，打开模型运行目录中的 results.csv。
    2. 在上方选择文件（或尝试示例），点击“分析日志”。
    3. 查看训练和验证曲线、最佳 mAP 的 epoch，以及自动检测到的可疑现象。
    4. 下载一份可离线打开的 HTML 报告；也可以通过浏览器打印保存 PDF。

    适用范围：主要面向常见目标检测训练日志；不支持直接分析 .pt 权重和没有 CSV 记录的训练过程。分隔符与引号按 CSV 标准解析；极端非标准日志可能无法正常分析。
